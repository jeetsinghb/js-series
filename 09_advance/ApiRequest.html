0	UNSENT -> Client has been created. open() not called yet.
        1	OPENED -> open() has been called.
        2	HEADERS_RECEIVED ->	send() has been called, and headers and status are available.
        3	LOADING -> Downloading; responseText holds partial data.
        4	DONE -> The operation is complete.
    
        The XMLHttpRequest (XHR) object is a built-in browser API that allows you to make asynchronous HTTP and HTTPS requests from JavaScript. Although it contains "XML" in the name, it can handle any data format, including JSON, HTML, and plain text.
        While modern projects typically use the newer, promise-based fetch() API, XMLHttpRequest remains widely supported and is necessary for legacy code or specific advanced use cases like tracking file uploadprogress.
